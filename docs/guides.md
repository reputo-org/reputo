# User guides

The dashboard includes short Scribe walkthroughs for presets, snapshots, communities, and admin access. Open **Guides** in Reputo or visit the [staging guides page](https://staging.logid.xyz/guides).

The `GUIDES` list in [`apps/ui/src/lib/guides.ts`](../apps/ui/src/lib/guides.ts) is the source of truth for titles, groups, and links.

## Add a guide

1. Record the task in Scribe on staging and share it as a public link.
2. Add the entry to `GUIDES` in [`apps/ui/src/lib/guides.ts`](../apps/ui/src/lib/guides.ts) with its group.
3. Open the Guides page and check the title, group, and embedded walkthrough.
